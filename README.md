# RAG Book Assistant

A Streamlit-based RAG app for uploading a PDF book, building a vector database with Hugging Face embeddings, and asking questions from the document.

## Features

- PDF upload via Streamlit
- PDF text extraction and chunking
- Vector store with `Chroma`
- Embeddings from `sentence-transformers/all-MiniLM-L6-v2`
- Retrieval using MMR
- Answers generated by `ChatMistralAI`

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the app

```bash
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal.

## Usage

1. Upload a PDF file.
2. Click `Create Vector Database`.
3. Wait for processing to complete.
4. Enter a question in the text input.
5. Read the AI-generated answer.

## Notes

- This project now uses Hugging Face embeddings locally, so an OpenAI API key is not required for the vector database.
- The app stores the vector database in `chroma_db_minilm_384`.
- If you change embedding or model dimensions, delete the database folder and rebuild.
